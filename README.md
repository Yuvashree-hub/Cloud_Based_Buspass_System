# Cloud-Based Ticket Booking System

A web-based ticket booking system that allows users to book and manage tickets online through a simple and user-friendly interface.

## Live Demo
cloud-based-buspass-system-rzo9.vercel.app

## Technologies
- Python
- Flask
- HTML
- CSS
- Cloud Technologies

## Features
- Online ticket booking
- Ticket management
- User-friendly interface
- Cloud-based deployment

## Objective
To develop a simple and accessible online platform for ticket booking using Flask and cloud technologies.
